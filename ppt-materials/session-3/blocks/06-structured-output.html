One API for structured output

Our #1 technique from Session 2 — but S2 needed three provider-specific parse calls. LangChain gives us one: with_structured_output().

a customer’s message
“I’ve been charged twice for May and nobody has replied. This is ridiculous.”
model.with_structured_output(Triage)
▤ Triage — a validated object back
category"billing"▾ dropdown
urgency"high"▾ dropdown
sentiment"negative"▾ dropdown
needs_humanTrue✓ escalate
summary"double charge, no reply"
triage.py
triage = model.with_structured_output(Triage)
t = triage.invoke(message)

t.category # "billing"
t.needs_human # True → a real bool

# one method · any provider · validated
💡 One catch: this returns the parsed object, not the message — so you lose token counts. Want them back? with_structured_output(Triage, include_raw=True) → keeps the envelope too (out["raw"].usage_metadata).
