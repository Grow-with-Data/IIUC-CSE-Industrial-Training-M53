The pattern behind every call

Client  →  Request  →  Read

Every LLM call — on every provider — is the same three moves. Learn it once and the rest is just different wording.

1

Make a client

A reusable connection that carries your API key from the environment.

from openai import OpenAI
oai = OpenAI()  # key auto-loaded
sends
"Say hello." ▸
2

Send a request

Your prompt + a model id go out to the provider. This is the network call.

resp = oai.responses.create(
  model=MODEL,
  input="Say hello.")
replies
◂ "Hello, class!"
3

Read the text out

Pull the answer off the response object and use it in your app.

text = resp.output_text
→ “Hello, AI engineering class!”
💬
Real-life: like texting a knowledgeable colleague — you send a message, you get a reply. Everything else in this course just controls how they answer.
